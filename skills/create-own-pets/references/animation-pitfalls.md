# 动画常见问题（animation-pitfalls）

| 问题 | 原因 | 解法 |
|------|------|------|
| 人物大小跳变 | 不同姿势在画布占比不同 | 用 `scaleMap` 为每个方向/姿势设置精确缩放，视觉大小统一 |
| 动画不流畅 / 卡顿 | 关键帧太少、或后台被节流 | 补过渡帧；关闭后台节流（Electron `backgroundThrottling: false`） |
| 动画抖动 / 闪烁 | 亚像素渲染 | transform 数值 `toFixed(4)`；图片切换不用淡入淡出，直接换 src |
| 动作冲突（拖拽中还在呼吸/张望） | 状态未互斥 | 状态机：一个动作开始时取消其他定时器（`isDragging` 时暂停一切自动动画） |
| 松手立刻躺下太突兀 | 无延迟 | 松手后 0.6s 恢复正面、3s 后回待机 |
| 打坐/待机时还在上下浮动 | 未按状态区分动画分量 | 待机只呼吸不浮动；呼吸幅度/速度随状态切换（如打坐更慢更浅） |
| 动画在后台变慢 | 浏览器节流 rAF | 关闭 backgroundThrottling，或用固定 dt 计算 |

核心原则：**动画分量（浮动/呼吸/跳跃）分开计算再组合，按状态门控；数值收敛到有限小数。**
