# 资产规格与生产流程（asset-generation）

> 无论哪种技术栈，桌宠的"形象资产"生产流程相同：**规格先行 → 生成 → 抠图 → 校验 → 命名**。

## 1. 资产规格说明书（先确认再产图）

向用户确认或生成以下规格（建议写入 `pet.config.json` 的 `character` 段）：

- **角色描述**：服装、发型、眼型、妆感、发色、体型（越具体越一致）
- **风格**：Q版 / 像素 / 写实 / 用户自带素材（3D 暂不实现）
- **方向列表**：1 / 4 / 8 / 自定义（决定资产数量）
- **表情/动作列表**：按交互需求（跳跃 / 睡觉 / 眨眼 / 伸懒腰…）
- **每张图要求**：透明背景 PNG、无地面阴影、无投影、指定视角、人物占比一致
- **命名规则**：`方向/动作.png`，与配置文件 assets 映射一致
- **是否需要左右翻转替代**（缺图时镜像，减少产图量）

## 2. 生成提示词模板

每张图的基础提示词骨架：

```
[角色描述]，[方向/姿势描述]，
纯白背景，无地面阴影，无投影，全身入镜，
透明背景 PNG 素材，人物居中
```

方向提示词示例：正面 `front`；背面要写明"真正的后脑勺，看不到脸"；侧面要求"脸部微转镜头，确保胸前图案清晰"。

## 3. 抠图

- **要求**：任意抠图工具均可，**只要求输出透明 PNG**。
- 示例（mediakit-cli，Q 版人物 `--scene general`）：

```powershell
$result = mediakit-cli image remove-image-background --image-url "<URL>" --scene general 2>&1 | Out-String | ConvertFrom-Json
curl.exe -sL -o "images\<文件名>.png" $result.image_url
```

- 注意：返回的 `image_url` 是临时链接，需立即下载；PowerShell 解析 JSON 需 `2>&1 | Out-String | ConvertFrom-Json`。

## 4. 校验清单

- [ ] 边缘干净、无残留背景
- [ ] 底部无阴影/残影
- [ ] 人物在画布中占比统一（不一致用 scaleMap 微调）
- [ ] 命名与配置 assets 一一对应
- [ ] 所有图风格、角色一致
