> 触发条件：贴图出现**多脚/多腿、假背面、侧面图案消失、底部灰影、角色不一致、边缘不净**等问题时。

# 贴图生成常见问题（asset-pitfalls）

> 角色贴图生成的共性问题与解法。按风格分两类：AI 生成类（Q版/写实）与像素/自带素材类。

## 1. AI 生成角色贴图

| 问题 | 原因 | 解法 |
|------|------|------|
| 眼睛过大 | 模型默认萌系倾向 | 反复强调"眼睛不要太大"，指定眼型（如细长上挑） |
| 复杂姿势肢体混乱（多脚/多腿/多指） | AI 在盘腿、跳跃、抬手等姿势上易出错 | 明确要求"双脚完全藏在裤腿下看不见"；或基于一张正常姿势图只改需要变化的部位；**不要擅自换成 AI 更擅长的姿势** |
| 背面生成成"头发遮脸"的假背面 | 模型误解"背面" | 明确要求"真正的后脑勺，看不到脸" |
| 侧面衣服图案消失 | 角度遮挡 | 要求"脸部微转镜头，确保胸前图案清晰可见" |
| 底部灰色阴影 | 模型默认加地面投影 | 每张图都要求"纯白背景，无地面阴影，无投影" |
| 底部灰色阴影 | 模型默认加地面投影 | 每张图都要求"纯白背景，无地面阴影，无投影" |
| 多张图角色不一致 | 每次生成随机漂移 | 以确认版正面图为锚点，其余图基于它生成/修改 |
| **带 AI 生成水印** | 生成工具强制叠加“AI生成”等文字标记（常在底部/角落，浅灰或半透明） | 生成后逐张检查；用像素级验证确认水印位置后再清理（避免视觉模型误把人物本体当水印）；清理后重新校验透明通道；**若为平台强制 AIGC 标记，按平台要求保留**，不擅自删除 |

## 1.1 水印清除的实测坑位（必读）

> 以下坑位来自实际项目（Q版角色 + 生成图右下角“AI生成”水印），直接抄作业可避免返工。

| 坑 | 现象 | 正确做法 |
|----|------|----------|
| **低估水印范围** | 凭视觉以为水印只在“右下角一小块”，只填白 x≥0.80w；实际水印从 x0.42 就出现，漏掉的部分被裁进成品 | **程序化扫描**：对右下区域做像素统计，取“中灰~浅灰、接近中性色”聚集像素的 bbox 作为水印区，范围宁大勿小 |
| **整块矩形填白切掉人物** | 人物脚部延伸到 y0.92-0.96，与水印区重叠；整块填白把脚也变透明，成品缺脚 | 填白时**只清浅色像素**（`r,g,b≥140 且 |r-g|,|g-b| 相近`），深色/暖色人物像素保留 |
| **裁剪范围交叉** | 裁剪 bbox（内容区）刚好覆盖水印左半段 | 裁剪前先填白水印区；裁剪后成品再扫描底部是否还有成片中灰条带 |
| **成品残影** | 缩放后水印边缘抗锯齿残留零星半透明灰点 | 成品重扫：底部/四角若有**成片**中性灰（一行多个连续浅灰）说明水印还在；零星 1-2px 低 alpha 边缘像素可接受 |
| **视觉模型误导** | ① 把鞋面暖色反光当水印误报；② 真水印却回复“角色本体” | 以像素级扫描为准（中性灰 + 聚集判断），视觉复核只作最终确认；两者结论冲突时按像素结果处理 |

> 判断水印 vs 人物反光的硬指标：**水印文字是中性灰/白色**（`|r-g|<10 且 |g-b|<10`），人物反光/皮肤是**暖色**（`r-b>15`）。底部区域若以暖色为主、中性灰稀少且分散，则无水印；若出现成片中性灰条带，则水印未清干净。

## 2. 像素风 / 用户自带素材

- 像素图：确认画布尺寸与缩放算法（最近邻，避免模糊）；方向切换可用左右镜像省图。
- 自带素材：先确认许可（版权），统一尺寸/比例，缺失方向用镜像+兜底。

## 3. 通用校验

- 边缘残留 / 白边 / 底色未除干净 → 重新抠图；
- 人物占比差异大 → 用 `scaleMap` 微调（见 `animation-pitfalls.md`）。
