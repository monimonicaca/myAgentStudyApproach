# 待机动画规则（idle）

## 0. 模式速查

| mode | 一句话 | 资产 |
|---|---|---|
| `none` | 完全静止，事件驱动，停止帧循环 | 仅 front 1 张，**禁止产其他图** |
| `breathe`（默认） | 程序化缩放+位移 | 仅 base 帧；**禁止产呼吸帧序列贴图** |
| `glance` | 随机换方向看一眼再回正 | 方向池≥2（1 方向项目用镜像）；真实侧脸 |
| `lying` | 换躺卧整图+极缓微呼吸 | lying.png + 可选躺下/起身过渡帧 |
| `loop` | 多个小动作各自独立触发播帧序列 | 每动作 2~6 帧，同锚点生成〔规范〕 |
| `mix` | 多子动作加权随机抽取，全局冷却 | =启用子动作资产之和；≥2 个子动作起效 |

## 1. 配置结构（唯一综合示例，按模式取用段）

```json
{
  "idle": {
    "mode": "lying",
    "params": {
      "entry": "hard-cut",
      "transition": { "down": "lying_start", "up": "lying_end" },
      "breath": { "breathScale": 0.012, "breathPeriod": 4.5 },
      "floatAmp": 6, "floatPeriod": 2.5,
      "scaleMap": { "lying": 0.82 }, "settleDelay": 3,
      "directions": ["left", "right"],
      "triggerInterval": [4, 8], "holdTime": [1, 2]
    },
    "actions": [
      { "name": "blink",
        "frames": [{ "asset": "blink_1", "duration": 150 }, { "asset": "blink_2", "duration": 300 }],
        "peakFrames": ["blink_2"], "triggerInterval": [10, 25] }
    ],
    "weights": { "glance": 0.25, "blink": 0.2, "stretch": 0.15 },
    "roundInterval": [6, 12], "breatheAlwaysOn": true,
    "fallbackMode": "breathe"
  }
}
```

- `fallbackMode`〔规范〕必填：当前模式不可用（资产缺失/参数无效）时的降级模式，兜底链尽头永远是**静态 front**。

## 2. 通用规范〔规范〕

1. **配置驱动**：周期/幅度/方向池/权重全部读 idle 段，代码不硬编码；
2. **状态优先级**：`isDragging` > 交互动作 > idle 内部动作；高优先级触发即 clear 低优先级定时器并复位 base；
3. **可打断恢复**：打断结束后按"延迟回待机"（示例 3s）重入 idle；
4. **互斥防重入**：每动作独立状态位，播放中不得再触发同动作；
5. **不连续重复**（glance/mix）：抽到与上次相同 → 重抽一次，仍同 → 跳过本轮照常冷却；
6. **数值安全**：入参先夹取到各模式参数表区间，越界夹取+日志，不抛异常；
7. **后台不冻结**：含持续动画的模式需 `backgroundThrottling:false`；时间基准用单调时钟（禁 Date.now〔规范〕），中间值 `toFixed(4)` 防亚像素抖动。

## 3. none（无动画）

- **实现**：进入后**终止帧循环**仅事件驱动〔规范〕（架构强制常驻 rAF 则用脏标记：无变化不重绘）；清空其他模式遗留定时器〔规范〕；
- **错误**：多余段（params/actions/weights）忽略+日志；任何错误的最终表现 = **回到静止**（本模式无可再降级）；
- **交付**：Performance 无持续重绘、CPU≈0；交互后回静态无残留状态位；删 base 帧重启降级链走到头仍不闪退。

## 4. breathe（呼吸浮动，默认）

| 参数 | 区间 | 默认 | 越界处理 |
|---|---|---|---|
| breathScale | 0.01~0.08 | 0.02 | 夹取+日志 |
| breathPeriod | 2.0~5.0 | 3.2 | 夹取+日志 |
| floatAmp | 0~12（0 合法=只呼吸） | 6 | >12 夹 12，负数夹 0 |
| floatPeriod | 2.0~4.0 | 2.5 | 夹取+日志 |

- **实现**：`scale=1+sin(t/period·2π)·breathScale`；浮动 `translateY=sin(t/floatPeriod·2π)·amp`；合成先 translate 后 scale；`origin: center bottom`〔规范〕（脚底不悬空）；交互帧动画期间**暂停呼吸变换**（帧内姿势与缩放叠加会扭曲），收势帧可叠加；
- **错误**：参数缺失→默认表；停摆（后台回来不动）→ 查 backgroundThrottling，仍不行降级 setInterval（保底 20fps）+ 交付说明标注；顿挫 → 查两周期是否近拍频（差<15% 调开）；
- **交付**：60fps 目标/30 保底；后台 10s 回来仍在动；拖拽即停/松手 3s 恢复；100 次 idle↔打断循环无句柄泄漏；幅度目测自然（无"喘气"）。

## 5. glance（随机张望）

| 参数 | 区间 | 默认 |
|---|---|---|
| directions | 有效方向名数组 | [left, right] |
| triggerInterval | 2~60 | [4, 8] |
| holdTime | 0.5~5 | [1, 2] |

- **实现**：链式 setTimeout 每轮重抽间隔（非固定 interval）；抽取**排除 front 与上次方向**〔规范〕；整图替换（无半透明中间态）；交互动作进行中到点 → 放弃本轮；
- **错误**：单方向缺 → 渲染降级链（镜像→轴向→front），降到 front 则本轮跳过；**整池空 → 切 fallbackMode** + 日志 + 交付说明标注"张望已降级"；重入失败 → isLooking 拦断+告警一次；池仅剩 1 方向 → 合法（隔轮触发）；
- **交付**：**100 次冒烟**无"中途卡住不回"/"连发两次"；间隔方差>0；删任一方向图降级链生效；删整池降级测试。

## 6. lying(躺卧休息)

| 参数 | 区间 | 默认 |
|---|---|---|
| entry | hard-cut / transition | hard-cut（过渡帧缺自动退硬切） |
| breath.breathScale | 0.005~0.02 | 0.012（比站立更小=熟睡） |
| breath.breathPeriod | 3.5~6.0 | 4.5（更慢） |
| scaleMap.lying | 0.6~1.0 | 0.82（补躺卧占比更高） |
| settleDelay | 1~10 | 3 |
| float | — | **禁止配置**〔规范〕（配了忽略+日志） |

- **产图坑**（躺图三坑）：AI 默认加地面影子→逐图要求"纯白背景无阴影"；躺姿多手多脚（重灾区）→ 基于正常坐姿只改躯干角度；头部视角错 → 与站图同镜头高度生成；
- **实现**：躺期只极小缩放**禁上下浮动**（熟睡稳定）〔规范〕；origin 用 `center`（躺姿无脚底）；scaleMap 按"躺/站占画布高度一致"对齐；唤醒链路 `mousedown → 立即回站立`（响应优先于动画：起身过渡中拖拽 → 跳过渡直接切〔规范〕）；双击跳跃后按配置回落（默认回躺）；
- **错误**：lying 缺 → fallbackMode + 日志 + 交付说明**必须标注**；占比跳变 → scaleMap 校准 → 不行回产图；唤醒后残留微缩放 → 验收"唤醒 5s 无残留"；
- **交付**：链路演示（松手→3s→躺下→微呼吸→拖拽即起身）；录屏逐帧证躺期无 translateY；删 lying 重启降级测试。

## 7. loop（循环小动作）

| 参数 | 区间 | 默认 |
|---|---|---|
| frames[].duration | 80~800ms | 250 |
| peakFrames | 有效帧名 | duration 最长帧 |
| triggerInterval（每动作独立） | 5~120 | [10, 25] |

- **实现**：setTimeout 链（帧时长不齐不用固定 interval）；**顶点帧停留 ×2~3**〔规范〕；**同一时刻只播一个**（A 播放中 B 到点 → B 丢弃等下轮）；打断即断不复播剩余帧〔规范〕；序列播放期间暂停呼吸变换；
- **产图**：同一动作所有帧**基于同一张锚点图逐帧改**〔规范〕（否则帧间角色漂移=废片）；相邻帧姿势连续；每帧独立过产图校验；
- **错误（帧级降级）**：中间帧缺 → **跳过该帧续播**（连跳 2 帧中止回 base）；**首帧缺 → 该动作整体禁用移池**；断链（异常无人续帧）→ 每帧回调 try/catch，catch 复位 base；帧尺寸跳变 → scaleMap 校准 → 不行该帧回产图；
- **交付**：**30 分钟连续运行无断链**（日志无 catch）；顶点停留可感知；逐帧删除测试三项（中间帧跳过/首帧禁用/全删降级）；100 次冒烟无卡半途。

## 8. mix（随机混合）

| 参数 | 区间 | 默认 |
|---|---|---|
| weights | 值>0，键=子动作名 | 全部均分 |
| roundInterval | 3~30 | [6, 12] |
| breatheAlwaysOn | bool | true（呼吸不占抽取名额） |

- **实现**：累积分布加权抽取（非法键删除后归一化）；剩余子动作播完 → 全局冷却〔规范〕；重抽一次仍同 → 跳过本轮（防连发）；抽中后执行转对应模式规则（§5/§6/§7），mix 只管"抽什么、何时抽"；打断后冷却不重置（不补播）〔规范〕；
- **错误**：某子动作资产缺 → 移池；只剩 breathe 常驻 → 退化为 breathe（合法）+ 交付说明标注；池全空 → 退 none；权重全 0/缺失 → 均分+日志；
- **交付**：**30 分钟频率 vs 权重 ±20%**（日志统计）；无固定节奏；逐个删除子资产 → 各自移池正常；冻结后冷却不重置。

## 9. 通用错误处理总表〔规范〕

| 故障层 | 处理 |
|---|---|
| 配置层（段缺失/mode 非法/参数越界） | 非法 mode→fallbackMode；缺失→默认参数表；越界→夹取；全程日志**不抛异常不闪退** |
| 资产层（子动作资产缺/损坏） | 该子动作禁用移池；模式整体不可用→切 fallbackMode；兜底链尽头=静态 front；交付说明列出降级项 |
| 运行时（停摆/丢帧/断链） | 停摆查 backgroundThrottling；丢帧记日志不阻断；**同一异常 10 分钟 >3 次 → 停动画转静态**（防雪崩） |
| 状态冲突（定时器堆叠/中途卡住） | 互斥位拦断 + 高优先级即 clear 低优先级定时器；100 次触发验证 |

## 10. 通用交付标准〔规范〕

- [ ] 功能：所选模式全部行为点逐条过（各模式"交付"行）；
- [ ] 恢复：任何打断后 3s 内回 idle 无卡死姿势；
- [ ] 性能：目标 60fps/保底 30；none 无持续重绘；后台不冻结；
- [ ] 健壮：**删除任一 idle 资产重启**，降级链工作+日志可读，无异常弹窗；
- [ ] 日志：每次降级/夹取/禁用有记录；
- [ ] 交付说明：列出降级项与参数默认值假设。
