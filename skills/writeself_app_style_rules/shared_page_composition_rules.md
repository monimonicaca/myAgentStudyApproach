# Shared Page Composition Rules

All pages should follow the same composition principles:

* **Use a clear vertical hierarchy:** Header → Primary Content → Secondary Content → Supporting Content.
* **Maintain generous negative space:** Keep sufficient breathing room between the screen edges, sections, and content groups.
* **Use a consistent horizontal margin:** Keep major content visually aligned to the same left and right boundaries.
* **Organize content into floating sections:** Group related content into rounded containers rather than creating dense full-width blocks.
* **Establish one primary focal point per screen:** One section should clearly dominate the visual hierarchy.
* **Use progressive visual hierarchy:** Primary content should be larger and more prominent; secondary content should remain visually quieter.
* **Prefer asymmetrical but balanced layouts:** Avoid rigid grid-based composition while maintaining overall visual balance.
* **Keep content density low:** Avoid placing too many independent elements within the same visual area.
* **Use consistent vertical rhythm:** Maintain predictable spacing between major sections and smaller internal elements.
* **Center visual elements when they are the emotional or analytical focus:** Charts, illustrations, key numbers, and mood indicators can occupy the visual center.
* **Keep decorative elements subordinate to content:** Illustrations and visual accents should support the composition rather than become the primary focus.
* **Maintain a soft, floating composition:** Avoid rigid borders, sharp rectangular blocks, or dense dashboard-style layouts.
* **Design for visual continuity:** Every page should feel like a variation of the same composition system rather than an independently designed screen.


### Negative Space Spacing Standard

Negative space must follow this spacing standard:

| Usage | Spacing |
|-------|--------:|
| Screen horizontal margin | **24dp** |
| Screen top/bottom breathing space | **24–32dp** |
| Between major sections | **16dp** |
| Between cards | **16dp** |
| Card internal padding | **16dp** |
| Between title and description | **8–12dp** |
| Between related elements | **8dp** |
| Between unrelated elements | **16dp** |
| Small icon/text spacing | **6–8dp** |

### Core Principle

> **Every page should use a calm, spacious, vertically layered composition with clear hierarchy, generous negative space, rounded content groups, and a single dominant visual focus.**
